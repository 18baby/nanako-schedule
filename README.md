# 일정 관리

테이블에 일정을 입력하면 캘린더에 자동으로 표시되는 사내 일정 관리 사이트입니다.

| 구분 | 사용 기술 |
|---|---|
| 프론트엔드 | React 18 + Vite, FullCalendar 6 (Nginx로 서빙) |
| 백엔드 | FastAPI + SQLAlchemy 2 |
| DB | PostgreSQL 16 |

## 실행

```bash
cp .env.example .env      # 비밀번호와 포트 수정 (생략하면 기본값 사용)
docker compose up -d --build
```

- 사이트: http://localhost:8080
- API 문서: http://localhost:8080/api/docs

## 기능

화면은 **일정 입력 / 일정 테이블 / 캘린더** 세 개의 탭으로 나뉩니다.

1. **일정 입력**: 값을 입력하고 [추가] 버튼이나 Enter를 누르면 등록됩니다 (상품명은 필수입니다).
2. **일정 테이블**
   - 리테일, 종류, 상태 필터로 원하는 일정만 볼 수 있으며, 이 필터는 캘린더 탭과 함께 적용됩니다.
   - 셀을 직접 수정하면 자동 저장됩니다. 텍스트와 날짜는 칸에서 벗어날 때, 선택 항목은 고르는 즉시 저장됩니다.
   - 컬럼 헤더를 클릭하면 정렬되고, 검색창은 전체 컬럼을 대상으로 검색합니다.
   - 리테일, 종류, 상태의 선택지는 `frontend/src/columns.js`의 `CATEGORY_OPTIONS`에서 바꿀 수 있습니다.
3. **캘린더**
   - 날짜형 컬럼 4개(전개일, APR입고일, 데이터입고일, 양산의뢰)를 하나의 캘린더에 표시합니다.
   - 색상: 전개일 파랑 / APR입고일 초록 / 데이터입고일 주황 / 양산의뢰 빨강
   - 표시 문구는 `상품명 · 날짜종류` 형식입니다.
   - 범례 체크박스로 날짜 종류별 표시를 켜고 끌 수 있습니다.
   - 일정을 클릭하면 테이블의 해당 행으로 이동합니다.

## 커스터마이징

- 상태 기본 선택지와 날짜별 색상은 `frontend/src/columns.js`에서 바꿀 수 있습니다.
- 컬럼을 추가하려면 `backend/app/models.py`, `backend/app/schemas.py`, `frontend/src/columns.js` 세 파일을 함께 수정해야 합니다.
  테이블은 처음 실행할 때 자동으로 만들어지므로, 이미 만들어진 테이블에 컬럼을 추가하려면 DB를 마이그레이션하거나 초기화해야 합니다 (`docker compose down -v`를 실행하면 모든 데이터가 삭제됩니다).
